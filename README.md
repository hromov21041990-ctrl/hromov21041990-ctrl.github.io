# PelletsGrupp — самостоятельный сайт

Перенос содержимого магазина Битрикс24: страницы, статьи, изображения, SEO-настройки и каталог 338 товаров. В Vulkan загружены все 64 модели девяти выбранных серий. BIOTEP — флагман. FACI поддерживает комплектации Base/Classico/Ottima и бункеры по данным производителя; GT имеет свою комплектацию. START содержит все девять автоматических пеллетных исполнений из актуального раздела производителя. ZOTA содержит 34 горелки и комплектующие в шести группах производителя.

## BIOTEP

Раздел `/biotep/` содержит четыре актуальные модели производителя: BIOTEP 18,
25, 32 и 77. В карточках опубликованы полные характеристики с индивидуальных
страниц моделей, описание возможностей, паспорта, схемы подключения, материалы
по очистке и сервису. Для BIOTEP 77 используются данные подробной карточки
модели: диапазон 18–77 кВт, площадь 150–1100 м² и КПД более 90%.

Снимок источника от 22.10.2026 хранится в `data/biotep-source.json`, обновление
карточек выполняется командой `python -B import_biotep.py`. Ссылки на документы
ведут в официальную библиотеку производителя на странице поддержки BIOTEP.

Раздел `/biotep/zapchasti/` содержит 83 запасные части BIOTEP с внутренними
артикулами PG-000261–PG-000343 и РРЦ с НДС из прайс-листа, действующего с
12 февраля 2026 года. Позиции распределены по десяти разделам: автоматика,
вентиляторы, шнеки, розжиг, горелка и дымоудаление, детали корпуса,
теплоизоляция, ПВХ-трубки, уплотнения и провода. Позиция с кодом 5627 исключена,
поскольку в исходном прайс-листе не указана РРЦ.

Из товарных строк прайс-листа извлечены 77 фотографий для 74 позиций ЗИП.
Для девяти товаров, у которых в исходном PDF нет фотографии, сохранена
нейтральная заглушка. Повторный импорт фотографий выполняется командой
`python extract_biotep_spare_images.py <путь-к-прайсу.pdf>`.

## Vulkan

Раздел `/vulkan/` содержит серии Boss (13), Eko (9), Eko-Max (5), Max-Duo (5), Optimum-Ultra (6), Optimum-Ultra-Pro (7), Optimum-Uni (8), Optimum-Uni-Max (6), Optimum-Uni-Pro (5). У каждой серии свой адрес, поиск и сортировка; у каждой модели — галерея, полная текущая цена производителя, характеристики, паспорт и кнопка звонка на основной номер. Собственное наличие не выводится из наличия поставщика.

Данные сверены 21.10.2026 с kras-kotel.ru. Источники и исходные значения сохранены в `data/vulkan-source.json`. Спорные площади пяти моделей и отсутствующая мощность шести Uni-Max отмечены как требующие уточнения. Девять существовавших адресов и идентификаторов Vulkan сохранены; при исходном переносе остальные 17 товаров не менялись. Снимок данных загружается через `import_vulkan.py`, для сборки используются `build.py` и `vulkan.py`; стили раздела — `vulkan.css`.

## Запуск

Python 3.12, зависимости из requirements.txt. Команды: `python build.py`, `python verify.py`. Публикуется папка dist. Для проверки достаточно любого статического хостинга. Исходные страницы: data/pages.json. Товары: data/products.json. Фотографии: assets.

По умолчанию сборка тестовая, с noindex. Для основного домена задайте `PRODUCTION=1 SITE_ORIGIN=https://pelletsgrupp.ru` при сборке после завершения проверки и подключения рабочего хостинга.

## Цены

`python sync_prices.py` сверяет точные модели BIOTEP, FACI, СТАРТ, Vulkan и все 34 позиции ZOTA с публичными источниками. Комплектации FACI и варианты бункеров START сверяются отдельно. Для ZOTA дополнительно проверяются артикул производителя и состав шести разделов. При ошибках сохраняются последние проверенные значения. Изменения цены более 30%, новые модели и изменившиеся варианты требуют проверки. Результаты: data/sync-status.json.

Подготовлены два GitHub Actions workflow: ежедневная проверка цен в 07:00 Екатеринбурга и публикация сайта в GitHub Pages после каждого изменения ветки `main`. Production-сборка использует домен `https://pelletsgrupp.ru`, включает индексацию, `robots.txt`, `sitemap.xml`, `CNAME` и проверку всех локальных ссылок.

## Публикация на GitHub Pages

1. Репозиторий размещается в аккаунте `hromov21041990-ctrl`.
2. Workflow `deploy-pages.yml` собирает папку `dist` с переменными `PRODUCTION=1` и `SITE_ORIGIN=https://pelletsgrupp.ru`.
3. `audit_production.py` блокирует публикацию, если остались ссылки на тестовый домен, `noindex`, старые телефоны, прежнее время работы или битые локальные ссылки.
4. В DNS меняются только записи сайта. MX, SPF, DKIM, DMARC и остальные почтовые записи домена сохраняются без изменений.
5. После выпуска сертификата GitHub Pages основной адрес — `https://pelletsgrupp.ru`; `www` направляется на основной домен.

## Состояние переноса

- Перенесён самостоятельный информационный сайт и каталог с выбором FACI.
- Статьи и основные страницы используют экспортированные адреса. Для окончательного переключения нужно сверить полный sitemap и адреса товаров старого каталога; подготовить серверные 301, если адрес изменён.
- Формы Битрикс24, корзина, оплата и личный кабинет не перенесены как работающие серверные функции. Сейчас заявки принимаются по основному телефону; в карточках также доступно копирование выбранной модели и комплектации.
- Две прежние сборные позиции ZOTA Fox с бункером и механизмом подачи сняты с сайта: таких готовых комплектов нет в текущем разделе поставщика. Их старые внутренние артикулы PG-000072 и PG-000073 сохранены в реестре и повторно не используются.
- Перед переключением основного домена: проверить опубликованную GitHub Pages-версию, сохранить почтовые DNS-записи, заменить только записи сайта, дождаться HTTPS и проверить основные маршруты на мобильном устройстве.
- Тестовый сайт опубликован отдельно, домен pelletsgrupp.ru и старый магазин не изменены.

# Постоянные внутренние артикулы

Все карточки оборудования и пеллет имеют поле `sku` вида `PG-000001`.
`data/sku-registry.json` — постоянный реестр соответствий ID сайта и артикулов.
При сборке `catalog_identity.prepare_catalog()` присваивает номера только новым
позициям. Существующие номера не меняются из-за цены, имени или порядка карточек.
Удалённые позиции остаются в реестре, их номера повторно не используются.
Реестр нужно хранить и переносить вместе с каталогом, не пересоздавать.

У FACI каждому сочетанию комплектации и бункера соответствует отдельный артикул
в `offers`. Исходная комплектация использует основной артикул карточки.
Постоянные `option_id` сохраняются при обновлении цен и перестановке вариантов.
Новые виды комплектаций требуют отдельного сопоставления с производителем.
Две позиции пеллет учитываются в тоннах; фасовка — параметр заявки.

Выгрузка для сопоставления с 1С: `python -B catalog_identity.py <каталог выгрузки>`.
Она содержит 258 активных уникальных артикулов для 131 карточки, включая 111 дополнительных
сочетаний FACI и 16 дополнительных вариантов бункеров START. Поля `Код 1С` и `GUID 1С` пока пусты: связь с записями базы 1С
ещё не установлена. Сначала сопоставить существующие записи, затем создавать
действительно отсутствующие. Не создавать дубликаты по одной только разнице имён.


## FACI

В разделе /faci/ перенесены все 18 моделей пеллетного раздела производителя.
GT имеет мощность 10–40 кВт, Ottima и бункер 300 л. FACI 1500 имеет только
Base/Classico и штатный бункер 2500 л, FACI 1000 — 2000 л. Всего 51 комплектация
и 129 сочетаний со штатными бункерами. Внешние DI STRADA — отдельные аксессуары,
в перенос не входят. Все прежние ID, адреса и артикулы сохранены.

Снимок: data/faci-source.json, сверка 21.10.2026. Галереи — из карточек производителя,
описания — фактические краткие изложения. Документы — сертификаты, паспортов
в карточках не найдено. Цена — текущая полная цена, без зачёркнутой прежней цены.
Импорт: python -B import_faci.py <каталог снимка>. Данные иных брендов не меняются.

При выборе FACI обновляются цена, артикул, описание, оснащение и таблица
характеристик. Для увеличенного штатного бункера габариты и вес отмечаются
как требующие уточнения: отдельных подтверждённых значений у производителя нет.
При возврате к базовому бункеру восстанавливаются исходные характеристики.
Данные представлений всех 129 сочетаний формируются из одного снимка каталога.
Версия site.js в адресе ресурса зависит от его содержимого, чтобы браузер
получал исправления при следующем открытии карточки.

## START

В разделе `/start/` опубликованы девять карточек только из официального раздела
автоматических пеллетных котлов: 20-GR, 30-GR, 30-GR-V2, 35-GR, 50-GR,
100-GR, 100-GR с правым бункером, 100-GR с автозолоудалением и 100-GR-MAX
мощностью 150 кВт. Сверка выполнена 22.10.2026.

Для каждой карточки перенесены текущая полная цена, галерея, характеристики,
состав базовой поставки, инструкция, декларация, чертежи и доступные 3D-модели.
Выбор штатного бункера меняет цену, внутренний артикул, описание и таблицу
характеристик. Временно недоступные у производителя бункеры помечаются в
выбранной конфигурации. Снимок источника хранится в `data/start-source.json`;
импорт выполняется `python -B import_start.py <каталог снимка>`.

## ZOTA

Раздел `/zota/` повторяет структуру поставщика: пеллетные горелки (3), бункеры
(8), механизм подачи (1), адаптеры (17), отбойники (4) и автоматика для горелок
(1). Для каждой позиции создана отдельная карточка, собственный постоянный
артикул `PG-000227`–`PG-000260`, локальная галерея, текущая цена и артикул
производителя. Для трёх горелок перенесены полные характеристики и шесть ссылок
на паспорта и инструкции контроллера.

Снимок официального каталога от 22.10.2026 хранится в `data/zota-source.json`.
Сбор снимка выполняет `research_zota.py`, импорт —
`python -B import_zota.py <каталог снимка>`. Наличие поставщика хранится только
как справочное поле и не показывается как собственный склад PelletsGrupp.
