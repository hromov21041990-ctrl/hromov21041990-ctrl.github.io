# Переключение pelletsgrupp.ru на GitHub Pages

Сначала должен успешно отработать workflow `Deploy PelletsGrupp to GitHub Pages`,
а в настройках репозитория **Settings → Pages** должен быть сохранён custom domain
`pelletsgrupp.ru`. Только после этого меняются DNS-записи сайта.

## Записи сайта

Удалить прежние `A`/`AAAA`-записи для корня домена `@`, которые ведут на старый
хостинг, и добавить:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| AAAA | @ | 2606:50c0:8000::153 |
| AAAA | @ | 2606:50c0:8001::153 |
| AAAA | @ | 2606:50c0:8002::153 |
| AAAA | @ | 2606:50c0:8003::153 |
| CNAME | www | hromov21041990-ctrl.github.io. |

GitHub рекомендует настраивать одновременно корневой домен и `www`. После
распространения DNS GitHub автоматически направит `www.pelletsgrupp.ru` на
основной адрес `pelletsgrupp.ru`.

## Записи, которые нельзя менять

Не удалять и не редактировать `MX`, `TXT`, SPF, DKIM и DMARC: они обслуживают
корпоративную почту `@pelletsgrupp.ru`. Не создавать wildcard-запись `*`.

## Порядок без простоя

1. Опубликовать репозиторий и проверить временный адрес GitHub Pages.
2. В `Settings → Pages` сохранить `pelletsgrupp.ru`.
3. Сохранить снимок текущей DNS-зоны, особенно почтовых записей.
4. Если возможно, заранее уменьшить TTL записей сайта до 300 секунд.
5. Заменить только записи `A`/`AAAA` корня и `CNAME` для `www`.
6. Проверить главную, каталог, карточку FACI, пеллеты, монтаж, сервис и контакты.
7. После выпуска сертификата включить **Enforce HTTPS**.

Распространение DNS и выпуск HTTPS могут занять до 24 часов. Старый Битрикс-сайт
не удалять до завершения проверки основного домена.
